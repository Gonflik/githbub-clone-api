# github-clone-api

A GitHub-like REST API built with Django and Django REST Framework.

**🚧 Currently in development**

---

## Features

* **Authentication** — JWT-based authentication
* **Users** — user profiles
* **Repositories** — create, edit, delete, and manage public/private repositories
* **Stars** — star and unstar repositories
* **Issues** — create, edit, close, and reopen issues
* **Comments** — comment on issues
* **Permissions** — role-based access control
* **Repository collaboration** — invite/remove collaborators, WRITE permissions, repository ownership transfer
* **Organizations** — create, edit, and delete organizations, member management, and roles
* **Organization repositories** — transfer repositories to organizations and manage organization repository listings

---

## Tech Stack

**Backend**

* Python / Django
* Django REST Framework
* PostgreSQL
* Redis (planned)
* Celery (planned)

**Testing**

* pytest

**Infrastructure**

* Docker

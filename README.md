# github-clone-api

A GitHub-like REST API built with Django and Django REST Framework.

**🚧 Currently in development**

---

## Features

- **Authentication** — JWT-based authentication
- **Users** — user profiles
- **Repositories** — create, edit, delete, and manage public/private repositories
- **Stars** — star and unstar repositories
- **Issues** — create, edit, close, and reopen issues
- **Comments** — comment on issues
- **Permissions** — role-based access control
- **Organizations** — organization and member management **(in development)**

---

## Tech Stack

**Backend**
- Python / Django
- Django REST Framework
- PostgreSQL
- Redis(planned)
- Celery(planned)

**Infrastructure**
- Docker
- pytest
